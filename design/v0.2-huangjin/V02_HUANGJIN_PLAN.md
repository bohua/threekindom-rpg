## 0. 一页概览

**0.2 玩什么**：涿郡三战之后，刘关张随邹靖南下，拜见恩师卢植，打颍川夜战、在火光里第一次见到曹操；回程眼看恩师卢植被槛车押走，又在广宗救下董卓，却被他当成“白身”轻慢；然后以功授安喜县尉，替县民办几件事、剿一场山贼，最后鞭打督邮、挂印而去。

**情感曲线**：意气风发（颍川火攻）→ 恩师蒙冤（槛车）→ 受辱（董卓）→ 小小的“有功”（安喜委托、剿匪）→ 再受辱（督邮）→ 弃官的痛快与失落：**官印丢了，人心留下了**（县民送行）。

**规模**：

| 项目 | 数量 |
| --- | --- |
| 新战斗 | 3 场（战斗 4 颍川夜战、5 广宗救董卓、6 安喜剿匪） |
| 新可走场景 | 2 个（卢植大营、安喜县）＋ 1 个纯演出场景（广宗官道） |
| 新战斗背景 | 3 套（颍川草泽夜营、广宗城外原野、安喜山麓） |
| 过场 | 13 段（§5），其中 2 段含玩家选择 |
| 新系统与扩展 | 5 项：战场事件、友军与护卫目标、记忆写入最小版（含可见提示与记忆栏）、混乱状态、等级上限 5→7；另有行军过场（应做，可用字卡兜底） |
| 水墨画卷收尾 | 新增 2 卷（第二节末、第三节末），“完成”印章只在版本最后一卷 |
| 体量 | 约为 Alpha 0.1 的 2.5 倍（producer 重估）；预计游玩时长再加 40–60 分钟（待实测） |

**结尾**：挂印出走、县民送行，然后“后事预告”旁白按剧本 v1.0 顺序（投公孙瓒→讨董→平原→北海→徐州）一句一句点到接掌徐州，接水墨画卷③与“完成”印章。停在 0.2，故事也能收尾。

```

   ↓ 南门（确认框：离开后不能返回）→ 行军（涿郡→广宗）

   ↓ 行军（颍川→广宗）

   ↓ C9 天下图旁白：张角病死，皇甫嵩破张梁、张宝；刘备授安喜尉 → 画卷②「黄巾转战」
   ↓ 年份跳到 185（N2）
安喜县（可走，到达时段落自动存档）：C10 到任 → 委托×3 → 县吏报山贼 → 东门 →【战斗 6 安喜剿匪】→ 回城，仍可自由走动
```

**不能回访的处理**：离开涿郡、卢植大营、安喜时都弹确认框，框内列出**未完成的委托**和“离开后不能返回”。“不能回访”做成年份节点状态机里的**进度步骤**（见 SYSTEMS_V02 §5），不靠禁用场景实现；存档永远不会落在已关闭的场景。
