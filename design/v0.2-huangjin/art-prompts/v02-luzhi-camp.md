# Codex 任务：0.2 广宗·卢植大营（场景 S1）

先读通用规则：`/mnt/project-files/art/v02-common-rules.md`（PC 上同名文件）。设计依据：`design/v0.2-huangjin/V02_HUANGJIN_PLAN.md` §3.1、§6.2。

## 这是什么地方
中平元年（184），北中郎将卢植率汉军围张角于广宗（冀州巨鹿）。刘关张来营中拜见恩师。玩家可在营里自由走动、和士卒说话、在军需官处补给，再从营门出发去颍川。

## 一营一景（特色）
- 这是**朝廷正规军**的营：汉军**赤色**旗帜、营帐成行成列、鹿角和木栅整齐、望楼两座；和 0.1 黄巾营的杂乱粗布帐篷形成强烈对比。
- 中军大帐最大，帐前立“盧”字将旗（繁体）和一面赤色大纛。
- 远景：巨鹿平原一望无际，地平线上有广宗城的城墙剪影，城头隐约黄旗（张角守城）。
- 午间明亮日光，营中地面是踩实的黄土，夹着车辙和马蹄印，边缘有青草。

## 布局（约 60×40 米，玩家从南面营门进）
| 区块 | 位置 | 要求 |
| --- | --- | --- |
| 营门 | 南边中央 | 木栅门、两侧望楼；门内外各留空地；两名守卒站门两侧 |
| 主道 | 营门直通中军帐 | 宽 ≥4 米，两侧营帐成行 |
| 中军大帐 | 北边中央 | **帐前留 ≥8 米×10 米空场**（演出要站 5–6 人）；**卢植站帐门前**，亲兵站帐门旁 |
| 军需帐 | 主道东侧 | 帐门前 ≥6 米空地，堆粮袋、箭捆；军需官站帐门口 |
| 伤兵帐 | 主道西侧 | 帐前草席上躺坐两名伤兵，帐门前留空 |
| 马厩 | 东北角 | 木棚、马槽、几匹马 |
| 校场一角 | 西北角 | 兵器架、箭靶；老卒站校场边 |
