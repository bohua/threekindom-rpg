# Codex 任务：0.2 新增 UI 设计图与切片

先读通用规则：`/mnt/project-files/art/v02-common-rules.md`。设计依据：`design/v0.2-huangjin/SYSTEMS_V02.md` §1–§5。

## 风格
- 和现有界面一套：`UI_STYLE_GUIDE.md`（深靛蓝底、银白细框、象牙白字）、0.1 战斗 UI 皮肤（`art\battle-ui\`、`art\battle-ui-enemy\`）、指令卡（`art\battle-ui-commands\`）、对白框与选项条（`art\ui-bubbles-bars\`）、游戏菜单（`GAME_MENU_UI_REDESIGN.md`）。**新元素必须像同一套里补出来的**，不另起风格。
- 界面文字用简体中文。

## 第一步：设计图（各 1920×1080，画在 0.1 现有战斗画面或城镇画面截图上）
1. `ui_battle_event_concept.png`：战斗中出现**战场事件横幅**（屏幕中上方，“火起！”）与**回合目标栏**（左上，“坚守！火攻将于下回合发动”／“援军将至：坚持到第 5 回合”，含回合数字）。
2. `ui_escort_concept.png`：战斗 5 画面：我方 3 人＋第 4 位**友军董卓本阵**，友军兵力条用绿色边框＋“护”字标记；回合目标栏“保护董卓本阵（剩 2 回合）”；刘备选“整队”时可以把光标移到董卓身上。
3. `ui_status_chaos_concept.png`：敌方单位头顶“混乱”图标＋状态栏文字“混乱（剩 1 回合）”。
4. `ui_memory_concept.png`：对白里两个选项（沿用现有选项条），选完后右下角提示“卢植记住了这件事”；另画武将界面里的“记忆”栏（列出几句“××记得：……”），放在现有武将页的哪一格由你按 `GAME_MENU_UI_REDESIGN.md` 的版式提出方案。
5. `ui_march_concept.png`：**行军过场**：天下图 r2 局部（`art\world-map-chapter1\` 已获批那张），刘备部队棋子、一条橙色虚线路线、起止地名、顶部年号“中平元年（184）”、右下角“跳过”按键提示；另画途经宛城时弹出的二选一框（“上前观战／继续赶路”）。
6. `ui_leave_confirm_concept.png`：离开卢植大营时的确认框“离开后不能返回，确定出发？”。

## 第二步：切片
横幅底板（可九宫格拉伸）、回合目标栏底板、友军兵力条边框与“护”字标记、混乱图标（16/24/32 三档）、记忆提示底板、记忆栏条目底板、行军棋子（刘备旗号，4 帧小步动画）、路线虚线段与端点、宛城等途经点图标。全部按现有 UI 切片的尺寸与命名规则输出。
