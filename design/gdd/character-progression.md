## Summary

固定成长、自动学技的武将成长系统：刘关张三人共享等额经验，按累计经验表从 1 级升到最多 5 级，每级按固定值增加武力／统率／智力，1 级和 3 级各自动获得一项技能。在 Alpha 0.1 里，三场教学战的经验让三人战后依次到 2／3／4 级，第三战前解锁第二技能。

> **Quick reference** — Layer: `Foundation` · Priority: `MVP` · Key deps: `战斗系统, 存档与战前快照, 游戏界面`

## Overview

系统持有每名可操作武将（刘备、关羽、张飞）的等级、累计经验、三核心属性和已解锁技能。战斗胜利时，它接收本场经验，给三人各加同样的数量，按经验表判断是否升级，升级后按固定成长表提高属性、按等级自动解锁技能。玩家不手动加点，没有成长分支、兵种晋阶或转职。玩家感受到的是「每打完一场，三兄弟一起变强，第三战前拿到新技能」。派生属性（兵力、技力、物攻等）的公式归战斗系统，本系统只提供等级和三核心属性。

## Detailed Design

### Core Rules

1. **可成长武将**：首版只有刘备、关羽、张飞三人。赵云不进入成长菜单（V1_SPEC §1、§3）。
2. **等级范围**：1–5 级，数据上限 5。
3. **累计经验表**：0／10／30／60／100，分别对应 1／2／3／4／5 级。
4. **经验来源**：只有三场黄巾教学战，分别发 10／20／30 经验，每场只发一次。可选非战斗支线首版不发经验（Alpha 0.1 不含支线）。
5. **等额经验**：刘关张获得等额经验，不按出战人数稀释（V1_SPEC §7）。未出战、或出战后兵力归零撤退的武将是否也获得经验，V1_SPEC 未写明【用户 2026-10-19 确认，见 Open Questions 1】。
6. **固定成长**：每升 1 级，三核心属性按下表固定增加；属性上限 100，超出部分截断。

   | 武将 | 1 级 武力／统率／智力 | 每级增加 |
   | --- | --- | --- |
   | 刘备 | 65／75／75 | +1／+2／+2 |
   | 关羽 | 90／80／60 | +2／+2／+1 |
   | 张飞 | 95／75／45 | +3／+2／+1 |

7. **自动学技**：1 级获得第一技能，3 级自动获得第二技能（刘备：整队→火矢；关羽：突击→破阵；张飞：横扫→威慑）。技能效果归战斗系统。
8. **入队等级**：关羽、张飞在第一战之前入队，入队时为 1 级、0 经验（V1_SPEC 流程推出：三人在三战中同步到 2／3／4 级）。
9. **结算时机**：经验在战斗胜利结算时发放；升级、属性提高和技能解锁在同一次结算中完成。战败不发经验。
10. **节奏目标**：本版通关自然到 4 级；不以 5 级为验收条件，不为到 5 级补战或刷级。
11. **重试与读档**：战败重试时，经验、等级、属性与技能还原为战前快照；读取更早存档后，再次完成同一场战斗可以正常获得一次经验（防重标志属于当前存档进程）。

### States and Transitions

| 状态 | 进入条件 | 转换 |
| --- | --- | --- |
| 未入队 | 新游戏时关羽、张飞 | 入队事件 → 已入队（1 级，0 经验，第一技能已解锁） |
| 已入队，等级 L | 入队或升级 | 战斗胜利发放经验，累计 ≥ 下一级门槛 → 等级 L+1（一次跨两级时逐级处理：实现默认，V1_SPEC 未写，首版数据不会出现） |
| 满级（5 级） | 累计 ≥ 100 | 不再升级（首版正常流程达不到） |

## Formulas

### 当前等级

`level = max{ L | xp_table[L] ≤ cumulative_xp }`，`xp_table = [0, 10, 30, 60, 100]`（L = 1…5）

| Variable | Type | Range | Source | Description |
| --- | --- | --- | --- | --- |
| cumulative_xp | int | 0–100（首版实际 0–60；上限处理待 Open Questions 2 确定） | 计算 | 累计经验 |
| xp_table | int[5] | 0–100 | data file | 各级门槛 |

**Output Range:** 1–5；首版流程 1–4。
**Example:** 0 → 第一战 +10 = 10（2 级）→ 第二战 +20 = 30（3 级）→ 第三战 +30 = 60（4 级）。

### 等级 L 的三核心属性

`stat(L) = min(100, base_stat + growth × (L − 1))`

| Variable | Type | Range | Source | Description |
| --- | --- | --- | --- | --- |
| base_stat | int | 1–100 | data file | 1 级武力／统率／智力 |
| growth | int | 1–3 | data file | 每级固定增加 |
| L | int | 1–5 | 计算 | 当前等级 |

**Output Range:** 1–100。
**Example:** 张飞武力 3 级：95 + 3 × 2 = 101 → 截断为 100。刘备智力 4 级：75 + 2 × 3 = 81。

| 武将 | 2 级 | 3 级 | 4 级 | 5 级 |
| --- | --- | --- | --- | --- |
| 刘备 | 66／77／77 | 67／79／79 | 68／81／81 | 69／83／83 |
| 关羽 | 92／82／61 | 94／84／62 | 96／86／63 | 98／88／64 |
| 张飞 | 98／77／46 | 100／79／47 | 100／81／48 | 100／83／49 |

（武力／统率／智力；由公式计算，非新增数值。）

## Edge Cases

- **若一次发放的经验跨过两级门槛**：逐级升级，每级都应用固定成长和技能解锁检查。这是实现默认，V1_SPEC 未写；首版数据不会出现。
- **若属性加成后超过 100**：截断为 100（张飞武力 3 级起即为 100）。
- **若已满 5 级仍获得经验**：首版流程达不到；处理方式【用户 2026-10-19 确认，见 Open Questions 2】。
- **若战败**：不发经验；重试时等级、经验、属性、技能还原为战前快照。
- **若读取更早存档后再次完成同一场战斗**：按当前存档进程的标志，正常发一次经验。
- **若第三战开始时不足 3 级**（例如通过非正常途径跳过前两战）：首版流程中不可能，前两战是第三战的前置条件（剧情事件持有）。
- **若武将未入队**：不获得经验、不出现在成长菜单。

## Acceptance Criteria

- **GIVEN** 新游戏，**WHEN** 开始游戏，**THEN** 刘备为 1 级、0 经验，已有整队。
- **GIVEN** 新游戏，**WHEN** 关羽、张飞入队，**THEN** 两人为 1 级、0 经验，已有第一技能（突击／横扫）。
- **GIVEN** 刘关张都是 1 级且三人均出战，**WHEN** 第一战胜利，**THEN** 三人各得 10 经验并升到 2 级。
- **GIVEN** 三人均出战并赢下前两战，**WHEN** 查看武将页，**THEN** 三人为 3 级，并已解锁火矢、破阵、威慑。
- **GIVEN** 三人均出战并赢下第三战，**WHEN** 结算，**THEN** 三人累计 60 经验、4 级。
- **GIVEN** 张飞升到 3 级，**WHEN** 查看属性，**THEN** 武力为 100（不是 101）。
- **GIVEN** 刘备升到 4 级，**WHEN** 查看属性，**THEN** 为 68／81／81。
- **GIVEN** 战斗失败，**WHEN** 选择重试，**THEN** 三人等级、经验、属性和技能与战前一致，失败不发经验。
- **GIVEN** 已完成第一战并领过经验，**WHEN** 读取第一战之前的存档再完成第一战，**THEN** 这次也正常获得 10 经验，且只获得一次。
- **GIVEN** 任一升级，**THEN** 没有手动加点、成长分支或转职入口。
- 实现中经验表、成长值、技能解锁等级均来自数据文件，无硬编码。

`qa-lead` 未参与 — Lean 模式。

## Open Questions

以下推荐答案已由用户 2026-10-19 确认采用。负责人：Bohua；目标：进入 Technical Setup 前确定。

1. **未出战、或出战后撤退的武将是否获得经验？** V1_SPEC 说「等额经验，不按出战人数稀释」，没写这两种情况。**用户 2026-10-19 确认：都获得**，三人都按本场经验全额获得。依据：MEMORY.md 第 4 轮用户选择「后备共享经验」；V1_SPEC §7「第三战开始时为 3 级，可使用第二技能」要求三人同步成长；也避免玩家因编队或撤退吃亏。
2. **满 5 级后多出的经验怎么处理？** 首版流程达不到。**用户 2026-10-19 确认：经验停在 100，不再累计**，界面显示「已满级」。
3. **升级在哪里展示？** **用户 2026-10-19 确认：在战斗结算画面逐人展示**，城镇武将页可随时查看。
