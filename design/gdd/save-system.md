## Summary

本机存档系统：3 个涿郡手动存档位，加 1 个滚动的战前自动存档位，并在确认战前整备时建立快照，供战败重试还原。它保证读档总是落在安全地点或战前准备、不停在演出中间，奖励和事件标志在同一存档里一致、不重复发放。

> **Quick reference** — Layer: `Feature` · Priority: `MVP` · Key deps: `武将成长与技能, 装备道具与商店, 剧情事件与过场, 战斗系统`

## Overview

系统负责两件事。一是**存档**：玩家在涿郡用 3 个手动存档位保存进度；每次确认战前整备时，自动覆盖唯一的战前自动存档位。存档放在本机用户存档目录，不做云存档，不含账号或许可证数据。二是**战前快照**：确认整备时把编队、装备、库存、铜钱、经验和事件状态记下来；战败选择重试时先还原快照，玩家可以重新编队配装，再确认就形成新的战前状态。玩家感受到的是：失败没有成本，存档不会坏掉流程，奖励不会因读档或重试而重复。存档文件格式和序列化方式属于实现，将由 ADR 决定（→ becomes an ADR）。

## Detailed Design

### Core Rules

**存档位**
1. 3 个手动存档位，只能在涿郡保存（V1_SPEC §9）。手动存档入口在酒馆，由掌柜 N05 提供（ZHUOJUN_TOWN_DESIGN §3、§4，设计建议）；是否还允许在涿郡其他安全处从菜单存档【推荐暂用，待用户确认（2026-10-18），见 Open Questions 1】。
2. 1 个滚动的战前自动存档位：每次确认战前整备后自动写入，覆盖上一次的自动存档。
3. 存档放在本机用户存档目录；不做云存档；不含账号或许可证数据。

**保存内容**（V1_SPEC §9）
4. 章节；安全场景及具体落点；三场战斗的 ID 与安全阶段；关张入队、桃园完成、结尾完成标志；任务奖励标志；武将及成长（等级、经验、属性、技能）；当前编队；库存；装备归属；铜钱；游戏版本。事件状态即 `story-events.md`「剧情标志」表中的全部标志。
   - **安全阶段**的取值【推荐暂用，待用户确认（2026-10-18），见 Open Questions 6】。
   - **具体落点**：手动存档时为酒馆；自动存档时为该战的战前准备。

**读档**
5. 读档后从最近的安全地点或战前准备恢复，不恢复到动画播放中间。
6. 读取尚未结义的安全阶段（两人都已入队、结义未完成）时，桃园演出从开头重新播放；已完成的演出不重复播放；读档后不残留操作锁（V1_SPEC §2.1）。
7. 存档损坏或版本不支持时，提示玩家并保留原文件，不静默清空。如何判定「版本不支持」【推荐暂用，待用户确认（2026-10-18），见 Open Questions 7】。
8. 不得加载到不存在的可玩徐州落点（V1_SPEC §11）。

**战前快照与重试**
9. 快照与战前自动存档都在**确认整备之后**建立。
10. 快照内容：编队、装备、库存、铜钱、经验及事件状态（V1_SPEC §4 第 9 条）。
11. 战败选择重试：先还原快照，再允许重新编队配装；重新确认后形成新的战前状态（新快照、新自动存档）。
12. 重试不重复发奖，也不累计道具损失。

**一致性与防重**
13. 奖励、任务完成、桃园演出与结尾完成标志在同一存档状态内一致更新：要么都写入，要么都不写入。
14. 防重标志属于当前存档进程，不使用跨存档的全局标志。读取更早的存档后，仍能正常再完成事件并领奖一次。

### States and Transitions

| 状态 | 说明 | 转换 |
| --- | --- | --- |
| 城镇安全状态 | 在涿郡、无演出播放 | 酒馆存档 → 写手动存档位；南门出城 → 战前准备 |
| 战前准备 | 编队、配装、查看敌情 | 确认整备 → 建立快照＋写自动存档 → 战斗中 |
| 战斗中 | 不可存档 | 胜利 → 写入奖励与事件标志 → 城镇安全状态或结尾；失败 → 战败选择 |
| 战败选择 | 重试或返回标题【待定】 | 重试 → 还原快照 → 战前准备 |
| 演出播放中 | 不可存档、不可读档中断恢复 | 演出结束 → 城镇安全状态 |
| 测试版结束 | 第三战后简短过场之后 | 返回标题 |

## Formulas

本系统不定义可调的数值公式。配置常量：手动存档位 3、战前自动存档位 1（data file）。

## Edge Cases

- **若在演出播放中尝试存档**：不可存档。V1_SPEC §2.1 规定演出期间暂停自由移动、交互和队伍操作，酒馆存档入口属于交互，因此不可用。
- **若读档时两人都已入队但结义未完成**：恢复到安全地点后，从开头重播桃园演出。
- **若读档时结义已完成**：不再播放，不残留操作锁。
- **若存档文件损坏或版本不支持**：提示并保留原文件，不删除、不覆盖。
- **若胜利后没有手动存档就退出**：下次读到的是这一战的战前自动存档，需要重打这一战。V1_SPEC 没有胜利后自动存档，本文不另加。
- **若战败后玩家不重试而退出**：存档状态为战前自动存档（确认整备后写入），读它回到战前准备。
- **若重试时玩家改了编队或装备**：重新确认后覆盖快照与自动存档；旧快照作废。
- **若读取更早存档后再次打赢已打过的战斗**：按当前存档进程的标志，再发一次奖励（只一次）。
- **若胜利结算中途退出游戏**：奖励与事件标志要么全部写入、要么全部未写入（一致性规则 13）；具体写入时机由 ADR 决定。
- **若在第三战胜利后的过场中退出**：读档不会落在过场中间；落点【推荐暂用，待用户确认（2026-10-18），见 Open Questions 3】。
- **若手动存档位已有存档**：覆盖前是否确认【推荐暂用，待用户确认（2026-10-18），见 Open Questions 2】。

## Acceptance Criteria

- **GIVEN** 在酒馆存档，**WHEN** 打开存档界面，**THEN** 有且只有 3 个手动存档位可选。
- **GIVEN** 在战前准备确认整备，**WHEN** 进入战斗，**THEN** 战前自动存档位被写入；再打下一场时同一个位置被覆盖。
- **GIVEN** 战斗失败，**WHEN** 选择重试，**THEN** 编队、装备、库存、铜钱、经验和事件状态与确认整备时一致，用掉的军粮回来了。
- **GIVEN** 重试时改了编队并重新确认，**WHEN** 再次失败重试，**THEN** 还原到新的确认状态。
- **GIVEN** 两人已入队、结义未完成的存档，**WHEN** 读档，**THEN** 从安全地点恢复，桃园演出从头播放，播完后玩家可正常操作。
- **GIVEN** 结义已完成的存档，**WHEN** 读档，**THEN** 不再播放演出，玩家可正常移动和打开菜单。
- **GIVEN** 存档文件损坏，**WHEN** 读档，**THEN** 显示提示，原文件仍在、未被改动。
- **GIVEN** 已领过第一战奖励的存档进程，**WHEN** 读取第一战前的存档再打赢第一战，**THEN** 再领一次奖励，且只领一次。
- **GIVEN** 酒馆手动存档和三场战斗各自的战前自动存档，**WHEN** 逐个读档，**THEN** 每个都落在对应的安全地点或战前准备，不在演出中间，也不在徐州。
- **GIVEN** V1_SPEC §9 所列的全部字段，**WHEN** 存档后再读档，**THEN** 每个字段与保存时完全一致。
- **GIVEN** 版本不支持的存档，**WHEN** 读档，**THEN** 显示提示，原文件不被修改或删除。
- **GIVEN** 三场战斗，**WHEN** 每场确认整备，**THEN** 各写入一次战前自动存档。
- **GIVEN** 在战斗中或涿郡以外，**WHEN** 尝试手动存档，**THEN** 不可用。
- **GIVEN** 演出播放中，**WHEN** 尝试打开存档，**THEN** 不可用。
- **GIVEN** 任一存档文件，**WHEN** 检查内容，**THEN** 不包含账号或许可证数据。
- 存档位数量来自配置，无硬编码。

`qa-lead`、`systems-designer` 未参与 — Lean 模式。

## Open Questions

以下推荐答案已按项目线程指示先行写入、暂用，均待用户确认。负责人：Bohua；目标：进入 Technical Setup 前确定。

1. **手动存档只能在酒馆，还是涿郡任意安全处都能从菜单存？** V1_SPEC 只说「涿郡手动存档」，城镇设计稿把入口放在酒馆。**推荐暂用，待用户确认（2026-10-18）：只在酒馆掌柜处存**，与城镇设计稿一致，也让酒馆成为回城整备的固定落脚点。
2. **覆盖已有手动存档前是否确认？** **推荐暂用，待用户确认（2026-10-18）：弹确认框**，避免误覆盖。
3. **第三战胜利后（简短过场／测试版结束）是否写存档？** **推荐暂用，待用户确认（2026-10-18）：不写新存档**，结束后返回标题，原有存档保持不变；要重玩就读之前的存档。代价：Alpha 0.1 中「结尾完成」标志不会写进任何存档。
4. **存档位摘要显示什么？** **推荐暂用，待用户确认（2026-10-18）：章节、地点、刘备等级、铜钱、存档时间。**「游玩时间」不在 V1_SPEC §9 的保存字段里，要显示需用户另行批准。
5. **战败画面除了「重试」还给不给「返回标题」？** **推荐暂用，待用户确认（2026-10-18）：给**，返回标题后可读任意存档。
6. **「安全阶段」有哪些取值？** **推荐暂用，待用户确认（2026-10-18）：两种：「城镇安全状态」和「第 N 战战前准备（已确认整备）」。**读档只会回到这两种状态之一。
7. **怎样算「版本不支持」？** **推荐暂用，待用户确认（2026-10-18）：只读当前存档格式版本，其他版本一律提示并保留原文件**，测试版不做旧版本迁移。
