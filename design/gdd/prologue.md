# 序章「天下大势」（0.2 静态版）

状态：实装中（2026-10-27）。依据：`design/chapter1-rise/CHAPTER1_PROLOGUE.md` v0.1（用户 2026-10-27 18:30 确认）与第一篇章剧本 v1.1 §4。本文是 0.2 静态版的实现规格；0.3 换成编年过场工具驱动的完整版时另改。

## 1. 玩家流程

1. 标题画面选“新游戏”。
2. 序章自动播放（约 3 分 40 秒）：画卷三段 → 天下图五段 → 人物登场卡 → 涿郡城门告示栏远景。
3. 画面淡出后进入涿郡：刘备站在市集广场告示栏前、面向告示，获得操作权。读告示即触发已实现的“张飞从身后喝一声”。
4. 任何时候按确认键或取消键，出现“跳过序章？ 是／否”；选“是”直接进入第 3 步，选“否”接着播放。首次游玩也允许跳过。
5. 行旅菜单新增“史事”分页（史事簿）。第一条“中平元年前·序章”，确认后关闭菜单、重播序章，播完回到原地。右侧展开本条的史实依据（党锢、太平道、三路官军、刘焉榜文的演义归属）。

读档、战斗后回城、0.2 野外场景都不自动播放序章；只有标题“新游戏”会播。序章中途不存档；中途退出游戏，下次新游戏重新播放。

## 4. 系统

- `StoryCinematics.Prologue()`：故事层钩子，与画卷、片头同一套 View 注册方式；没有 View 时直接结束。
- `StoryCinematicsView`（部分类 `.Prologue.cs`）：全屏层，九镜按表播放；时间不冻结（城镇在序章开始前已设好落点）。
- `TitleController.NewGame` 置 `GameRun.PrologueDue`；涿郡 `Start` 见到它就先放序章，再把刘备放到告示栏前。
- `IFieldHost.PlayChronicle(id)`：史事簿重播，城镇和 0.2 野外两个宿主都实现；播放期间宿主为 Busy，不响应移动和交互。
- 音乐 cue `prologue_tianxia`（Suno 半自动，另行生成；缺文件为静音）。

## 7. 旁白配音与片头音乐（用户 2026-10-28：“旁白的语音我们需要做一下，同时片头需要背景音乐”）

- 旁白：每句字幕一段语音，`Resources/Audio/Voice/Prologue/prologue_<镜>_<句>.wav`（1 起）。一句字幕停留时间 = max(按字数的阅读时间, 语音长度 + 0.6 秒)；跳过确认弹出时语音暂停。缺文件的句子照常按阅读速度走。
- **当前为临时配音**：微软神经语音 zh-CN-YunyangNeural（语速 −8%、音高 −4 Hz），经 edge-tts 生成，响度 −16 LUFS、−1.5 dBTP、48 kHz 单声道。仅供试听和定节奏，商用授权不清，正式版需换成有商用授权的配音（真人配音或官方 TTS API）。读音修正只用于配音文本：“中平元年（184）”读“中平元年，公元一八四年”，“解人”读 xiè，“朱儁”读 jùn。
- 片头音乐：cue `prologue_tianxia`，不循环；旁白播放时音乐压到 40%（`StoryMusic.Duck`）。Suno 提示词卡见 `design/audio/suno-cards/prologue_tianxia.md`，由用户在 Suno 官方网页生成下载（ADR-0011）。
