## Summary

首版（Alpha 0.1「涿郡起兵」）的传统 JRPG 对列回合制战斗：每名武将率一支部队，兵力即 HP；玩家先为全队下令，再按速度统一结算。它承载三场黄巾教学战，教玩家下令、速度顺序、技力、步骑弓克制、防御和撤退，是首版验证「武将能力影响部队表现」的核心系统。

> **Quick reference** — Layer: `Core` · Priority: `MVP` · Key deps: `武将成长与技能, 装备与道具, 存档与战前快照, 剧情事件与教学提示, 战斗界面`
> （Category: Gameplay、Layer、Priority 均为推断 — 本仓库尚无 `systems-index.md`，待 `/map-systems` 确认）

## Overview

战斗系统负责一场遭遇从「战前准备」到「胜负结算」的全部规则。数据层面，它读取武将的三核心属性（武力／统率／智力）、等级、兵种与装备，派生出兵力、技力、物攻／物防、计攻／计防和速度；每回合收集我方全队指令与敌方固定 AI 指令，按「防御先行、其余按速度降序」结算伤害、恢复和增减益，并判定撤退与胜负。玩家层面，它是对列回合制：玩家每回合为最多 3 名出战武将各选一个指令（攻击、技能、防御、道具），提交前可修改，再观看双方按行动队列交锋。首版只服务 3 场黄巾教学战，没有随机遇敌、逃跑、暴击、闪避、连携、地形或战棋移动；它存在的意义是让刘关张的属性差异和步骑弓克制在少量战斗中清晰可读。

## Detailed Design

### Core Rules

**编队与开战**

1. 首版可出战武将仅刘备（弓兵）、关羽（骑兵）、张飞（步兵）。每场可选 1–3 名合法武将，默认三人共同出战；空队伍不可开战；战中不换人，没有后备自动接战。
2. 兵种首版固定：刘备弓、关羽骑、张飞步，不转职。
3. 每名武将率一支部队，**兵力即该单位 HP**，不另设个人 HP。当前兵力不降低攻击输出，只决定该单位是否还能作战。

**一场战斗的流程**（V1_SPEC §4）

1. **战前准备**：确认编队、配装、兵种与敌方情报；确认整备后建立战前快照并写入滚动战前自动存档。
2. **下令**：为每个可行动的我方单位选择 攻击／技能／防御／道具 之一；全队提交前可修改任意指令。
3. **敌方指令**：使用可解释的固定 AI 规则，读取**当回合开始时**的状态，不窥探我方尚未执行的指令。
4. **结算**：防御是唯一先行指令——在本回合任何伤害前生效，建立 50% 减伤，持续到回合结束；其余动作按双方速度从高到低执行。该防御例外需在界面中说明。
5. **同速**：我方先于敌方；同侧按固定出战位顺序，不临时随机。界面显示行动顺序。
6. **撤退**：兵力为 0 的单位本场撤退、不再行动；首版没有复活技能。
7. **失效目标**：普通攻击的目标已撤退时，转向第一个存活敌人；单体技能无合法目标则取消，不扣技力；道具目标无效或不需要恢复则取消，不扣道具；全体技能只作用于剩余合法目标。
8. **资源扣除**：技力与道具在动作**实际执行时**扣除；技力不足时该技能取消并提示，技力不扣成负数。每个单位每回合执行一次指令。**战斗中技力不自动回复**（用户 2026-10-18 确认），只在战后回满。
9. **胜负**：敌方出战单位全部撤退为胜利；我方出战位中的存活单位全部撤退为失败。**最后一个敌人撤退时立即判定胜利并结束回合**，本回合剩余动作不再执行（用户 2026-10-18 确认）。
10. **胜利**：发放一次奖励、恢复全队兵力与技力、推进事件。
11. **战败**：可还原战前编队、装备、库存、铜钱、经验及事件状态后重试；不重复发奖、不累计道具损失。

**伤害与克制**（V1_SPEC §5）

- 直接伤害分物理（物攻 vs 物防）与计策（计攻 vs 计防），公式见 Formulas。
- 先应用相关属性的增益／减益，再计算伤害。
- 兵种克制：骑克步、步克弓、弓克骑。敌方专用的黄巾军（被骑兵克）与文官／军师（不参与克制）规则见「敌方专用兵种规则」（用户 2026-10-18 确认，数值待试玩调整）。占优时最终伤害 ×1.4 一次；逆向不额外减伤；克制不另加攻击或削减防御。所有直接伤害技能使用此规则，治疗与辅助不套克制；多段攻击每段各自计算，不对同一段重复乘 1.4。
- 受击减伤系数：普通 1、防御 0.5。最终向下取整且至少为 1。
- 首版不提供暴击、闪避随机、连携、地形、逃跑、召唤和复杂状态叠加。

**增益／减益**（V1_SPEC §4 末段）

- 同一属性、同一方向的效果不叠加，只取较强效果并刷新持续时间。
- 不同属性的效果可共存。
- 同一属性同时有增益和减益时，倍率变化相加，最终倍率最低 0.2。
- 持续回合包含施放当回合；统一在回合结束时减 1，归零移除。说明中需标出剩余回合。

**技能**（V1_SPEC §6；首版 6 项）

普通攻击：系数 1.0，不耗技力。每将 1 级获得第一技能、3 级自动获得第二技能。

**道具**

- 首版战斗道具仅「军粮」：回复一支存活部队 30% 最大兵力，占用一次行动，不可复活（价格与库存规则归装备与道具系统，V1_SPEC §8）。

**成长与奖励**（V1_SPEC §7）

- 刘关张获得等额经验，不按出战人数稀释。累计经验表 0／10／30／60／100 对应 1–5 级，数据上限 5 级。
- 三场黄巾教学战各只发经验一次：10／20／30，战后依次到 2／3／4 级；第三战开始时为 3 级，可用第二技能。本版通关自然到 4 级，不要求 5 级，不为升级补战或刷级。
- 三战铜钱奖励 30／50／60（V1_SPEC §8，由经济系统持有）；第三战即本版最终战，使用同一份奖励记录。
- 剧情、任务与战斗完成标记属于当前存档进程；重试／读档不重复发奖。

设计意图：
- 第一战：敌方无技能，只有普攻。
- 第二战：只有张梁一名首领级单位（满足「不能将 4 人全部配置为首领强度」）。克制教学来自三方面：关羽骑兵对黄巾军和步兵都占优；张梁（步）克制刘备弓兵；刘备、张飞对黄巾军无克制。
- 第三战：张宝、张梁两名步兵被关羽克制，又克制刘备；张角不参与克制，但他的计策伤害和全体物攻减益是需要优先处理的威胁，用来练目标优先级、威慑与防御。

固定 AI 规则（用户 2026-10-18 确认，均读取回合开始时状态）：
1. **第一战**：每个敌人普通攻击当前兵力最高的存活我方单位（同值按出战位），让压力集中在张飞的厚兵力上，便于新手。
2. **第二、三战，选目标**：每个敌人攻击与自己出战位相对的我方单位（敌方第 N 位对我方第 N 位；敌方多于我方时，多出的单位对我方最后一位）；该单位在回合开始时已撤退则改打当前兵力最低者，同值按出战位。若目标在本回合结算中途才撤退，按核心规则 7 改打第一个存活单位。玩家可以通过安排出战位来分散压力。
3. **第二、三战，技能节奏**：有技能的敌人在第 3、6、9……回合且技力足够时用技能，其余回合普通攻击；技力不足时普通攻击。张角的技能回合交替使用两项技能：第 3、9、15……回合用威慑类，第 6、12……回合用火矢类。
4. 敌方不使用防御和道具。

### States and Transitions

**战斗阶段**

| 状态 | 进入条件 | 离开条件 → 下一状态 |
| --- | --- | --- |
| 战前准备 | 玩家触发某场教学战 | 确认整备（编队 1–3 人合法）→ 建立快照与自动存档 → 下令 |
| 下令 | 新回合开始 | 全队提交 → 敌方选指令 |
| 敌方选指令 | 我方提交 | AI 依回合开始时状态选定 → 结算 |
| 结算 | 指令齐备 | 防御先行 → 按速度逐个执行；每个动作后检查胜负：最后一个敌人撤退立即胜利（用户确认）；我方出战全员撤退立即失败（用户确认）；否则全部执行完进入回合结束 |
| 回合结束 | 所有存活单位已执行 | 增减益持续 −1、移除归零 → 下令（新回合） |
| 胜利 | 敌方全部撤退 | 发奖（一次）、全恢复、推进事件 → 返回探索／结尾过场 |
| 失败 | 我方出战存活单位全部撤退 | 玩家选择重试 → 还原快照 → 战前准备 |

**单位状态**

| 状态 | 说明 | 转换 |
| --- | --- | --- |
| 可行动 | 兵力 > 0 | 兵力降为 0 → 撤退 |
| 防御中 | 本回合选择了防御 | 回合结束 → 可行动 |
| 撤退 | 兵力 = 0，本场不再行动，不能作为治疗／道具目标 | 战斗结束后全恢复；本场内不可逆（无复活） |

**状态效果**：施放 → 生效（含当回合）→ 每回合结束剩余回合 −1 → 0 时移除；被同属性同方向更强效果覆盖时刷新持续时间。

## Formulas

所有变量均为数据驱动（data file），不在代码中硬编码。属性取值 1–100，升级后按上限截断。`floor` 为向下取整。

### 兵力上限

`max_troops = 80 + 20 × level + troop_type_bonus + equip_troops`

| Variable | Type | Range | Source | Description |
| --- | --- | --- | --- | --- |
| level | int | 1–5 | 成长系统 | 武将等级 |
| troop_type_bonus | int | 0／10／20／30 | data file | 步兵 +30、骑兵 +10、弓兵 0；敌方专用：黄巾军 +20、文官／军师 0 |
| equip_troops | int | 待定 | 装备 | 装备兵力加值 |

**Output Range:** 无装备时 100（弓 1 级）至 210（步 5 级）。
**Example:** 张飞 1 级步兵、无装备：80 + 20 + 30 = 130。

### 技力上限

`max_sp = 4 + 2 × level + equip_sp`

| Variable | Type | Range | Source | Description |
| --- | --- | --- | --- | --- |
| level | int | 1–5 | 成长系统 | 等级 |
| equip_sp | int | 待定 | 装备 | 装备技力加值 |

**Output Range:** 无装备时 6–14。
**Example:** 3 级：4 + 6 = 10。

### 物攻／物防／计攻／计防

`phys_atk = 10 + floor(STR / 2) + 2 × (level − 1) + equip_phys_atk`
`phys_def = 5 + floor(LEAD / 3) + (level − 1) + equip_phys_def + infantry_def_bonus`
`tac_atk = 10 + floor(INT / 2) + 2 × (level − 1) + equip_tac_atk`
`tac_def = 5 + floor(INT / 3) + (level − 1) + equip_tac_def`

| Variable | Type | Range | Source | Description |
| --- | --- | --- | --- | --- |
| STR／LEAD／INT | int | 1–100 | 武将数据＋固定成长 | 武力／统率／智力 |
| level | int | 1–5 | 成长系统 | 等级 |
| equip_* | int | 待定 | 装备 | 对应装备加值 |
| infantry_def_bonus | int | 0 或 5 | data file | 步兵额外 +5 物防（黄巾军、文官／军师为 0） |

**Output Range:** 无装备时约 物攻 10–68、物防 5–47、计攻 10–68、计防 5–42。
**Example:** 见下表（1 级、无装备，由公式计算，非新增数值）。

| 武将 | 兵力 | 技力 | 物攻 | 物防 | 计攻 | 计防 | 速度 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 刘备（弓，65／75／75） | 100 | 6 | 42 | 30 | 47 | 30 | 8 |
| 关羽（骑，90／80／60） | 110 | 6 | 55 | 31 | 40 | 25 | 10 |
| 张飞（步，95／75／45） | 130 | 6 | 57 | 35 | 32 | 20 | 6 |

固定成长（每级）：刘备 +1／+2／+2、关羽 +2／+2／+1、张飞 +3／+2／+1。

### 速度

`speed = base_speed(troop_type) + equip_speed`

| Variable | Type | Range | Source | Description |
| --- | --- | --- | --- | --- |
| base_speed | int | 6／7／8／10 | data file | 步 6、弓 8、骑 10；敌方专用：黄巾军 6、文官／军师 7 |
| equip_speed | int | 待定 | 装备 | 装备速度加值 |

首版不设独立敏捷。

### 伤害

`base_damage = atk_eff × skill_coef − def_eff × 0.5`
`final_damage = max(1, floor(base_damage × advantage × guard))`

| Variable | Type | Range | Source | Description |
| --- | --- | --- | --- | --- |
| atk_eff | float | ≥0 | 计算 | 物理用物攻、计策用计攻；已乘增减益倍率 |
| def_eff | float | ≥0 | 计算 | 物理用物防、计策用计防；已乘增减益倍率 |
| skill_coef | float | 0.65–1.5 | data file | 普攻 1.0、突击 1.5、火矢 1.3、破阵 1.1、横扫 0.65 |
| advantage | float | 1.0 或 1.4 | data file | 兵种占优 1.4，否则 1.0 |
| guard | float | 1.0 或 0.5 | data file | 普通 1、本回合防御中 0.5 |

**Output Range:** 至少 1；无上限截断。按当前敌方数值，普攻单次约 10–70，技能单次约 20–110（未测试；例如 2 级关羽普攻黄巾将领 67、突击 107）。
**Example:** 1 级关羽（骑）对第一战杂兵头领（黄巾军，物防 18）用突击：55 × 1.5 − 18 × 0.5 = 73.5；骑兵克黄巾军 ×1.4 = 102.9；目标未防御 ×1 → floor = 102。若目标本回合防御：floor(102.9 × 0.5) = 51。
**Example（计策）:** 3 级刘备（计攻 53）对张宝（计防 28）用火矢：53 × 1.3 − 28 × 0.5 = 54.9；弓兵对步兵不占优 → floor = 54。

### 增减益倍率

`stat_multiplier = max(0.2, 1 + Σ 各方向最强效果的变化量)`

| Variable | Type | Range | Source | Description |
| --- | --- | --- | --- | --- |
| 变化量 | float | 首版 −0.2 | data file | 破阵 物防 −20%、威慑 物攻 −20% |

**Example:** 目标同时有物防 +20% 与 −20% → 1 + 0.2 − 0.2 = 1.0；首版我方与敌方都没有增益技能，此情形目前不会出现，规则保留。

### 恢复

`heal = floor(max_troops × 0.3)`，结果不超过上限。整队与军粮相同，均不套克制。向下取整由用户 2026-10-18 确认。

| Variable | Type | Range | Source | Description |
| --- | --- | --- | --- | --- |
| max_troops | int | 100–210 | 计算 | 目标最大兵力 |
| 0.3 | float | — | data file | 恢复比例 |

**Example:** 张飞 1 级最大兵力 130 → floor(39.0) = 39；关羽 110 → floor(33.0) = 33；最大兵力 125 → floor(37.5) = 37。

### 经验与等级

`level = 满足 cumulative_xp ≥ threshold 的最大等级`，threshold = [0, 10, 30, 60, 100]，上限 5。
**Example:** 0 → 第一战 +10 = 10（2 级）→ 第二战 +20 = 30（3 级）→ 第三战 +30 = 60（4 级）。

`systems-designer` 未参与 — Lean 模式。我方数值按 V1_SPEC 原样转录；敌方数值与敌方专用兵种为本文起草、经用户确认；平衡待实测。

## Edge Cases

- **若普通攻击执行时目标已撤退**：改为攻击第一个存活敌人（按敌方出战位顺序）。
- **若单体技能执行时目标已撤退且无合法目标**：取消该技能，不扣技力。
- **若全体技能执行时部分敌人已撤退**：只作用于剩余合法目标。
- **若技力不足以执行已选技能**：执行时取消并提示，技力不变为负数（V1_SPEC）。因为战中技力只减不增，同一回合内我方技力不会被敌方改变，这种情况只会在下令菜单允许选择技力不足的技能时出现。用户 2026-10-18 确认：下令菜单把技力不足的技能置灰、不可选；执行时的校验保留作保护。
- **若道具目标已撤退或兵力已满**：取消，不扣道具。
- **若治疗目标已撤退**：撤退单位不可作为整队／军粮目标；首版无复活。
- **若计算后的伤害 ≤ 0**：按 1 计。
- **若双方速度相同**：我方先于敌方；同侧按固定出战位顺序。
- **若一个单位选择防御**：在本回合所有其他动作之前生效，即使该单位速度最低；持续到回合结束。
- **若同一属性同方向的减益再次施加**：不叠加，取较强值并刷新持续时间。
- **若同一属性同时有增益和减益**：倍率变化相加，最低 0.2 倍。
- **若持续 2 回合的效果在当回合施放**：施放当回合计第 1 回合，回合结束减 1，下一回合结束后移除。若目标在本回合已先行动，施放当回合的效果对其输出无实际影响（规则自然结果）。
- **若最后一名敌人在某动作中撤退**：立即判定胜利，本回合剩余动作不再执行，未执行动作的技力／道具不扣（用户 2026-10-18 确认立即判定）。
- **若最后一个我方出战存活单位在某动作中撤退**：立即判定失败，与胜利用同一时点规则（用户 2026-10-18 确认）。
- **若破阵命中**：本击按施放前的物防计算；物防 −20% 从该目标承受的下一击起生效。
- **若整队目标为刘备自身**：允许，按刘备最大兵力 30% 向下取整回复。
- **若技力不足且战中无回复**：该武将之后只能普攻、防御或用道具，直到战斗结束。
- **若我方出战存活单位在同一回合全部撤退**：判定失败；未出战武将不自动接战（首版本就没有后备）。
- **若战败后重试**：还原战前编队、装备、库存、铜钱、经验与事件状态；奖励与道具消耗不累计，可重新整备后形成新快照。
- **若读取更早的存档**：防重标记属于当前存档进程，读档后可再次完成该战并正常领奖一次。
- **若张梁在第二战兵力归零**：表现为部队溃退、本人撤走，不播放死亡或斩杀。

## Acceptance Criteria

- **GIVEN** 战前准备界面，**WHEN** 编队为 0 人，**THEN** 无法开战；1–3 名合法武将时可开战。
- **GIVEN** 下令阶段，**WHEN** 玩家已为部分单位选指令，**THEN** 提交前可修改任意单位的指令。
- **GIVEN** 敌方 AI 选指令，**WHEN** 我方已提交指令，**THEN** AI 的选择与我方指令内容无关（同一回合开始状态、不同我方指令下 AI 选择相同）。
- **GIVEN** 张飞（速度 6）选择防御、敌方骑兵（速度 10）攻击张飞，**WHEN** 结算，**THEN** 防御先生效，该次伤害按 0.5 系数计算。
- **GIVEN** 我方与敌方单位速度相同，**WHEN** 结算，**THEN** 我方先行动；同侧按出战位顺序，行动队列显示该顺序。
- **GIVEN** 1 级关羽（物攻 55，骑兵）对物防 18 的黄巾军目标使用突击，**WHEN** 目标未防御，**THEN** 伤害为 102。
- **GIVEN** 同上，**WHEN** 目标本回合防御，**THEN** 伤害为 51。
- **GIVEN** 任一我方单位攻击张角（文官／军师），**WHEN** 结算，**THEN** 不乘 1.4；张角攻击我方任一单位也不乘 1.4。
- **GIVEN** 3 级刘备（计攻 53）对计防 28 的步兵目标使用火矢，**WHEN** 结算，**THEN** 按计攻／计防计算，伤害为 54，不乘 1.4。
- **GIVEN** 张飞施放威慑，**WHEN** 物攻 51 的敌人在之后 2 回合内普攻物防 38 的步兵，**THEN** 按物攻 40.8 计算，伤害为 21（无威慑时为 32）；第 2 个回合结束后减益移除。
- **GIVEN** 我方出战单位全部撤退，**WHEN** 判定，**THEN** 战斗失败，进入可还原战前状态的重试选择。
- **GIVEN** 弓兵攻击骑兵，**WHEN** 结算，**THEN** 伤害乘 1.4；骑兵攻击弓兵时不乘 1.4、也不额外减伤。
- **GIVEN** 刘备使用整队，**WHEN** 目标为步兵（不论克制关系），**THEN** 回复量为目标最大兵力 30%、不乘 1.4、不超过上限。
- **GIVEN** 张飞使用横扫，**WHEN** 敌方剩 2 个存活单位，**THEN** 只对 2 个单位各计算一次 0.65 倍伤害，每个目标各自判断克制。
- **GIVEN** 计算出的伤害 ≤ 0，**WHEN** 结算，**THEN** 造成 1 点伤害。
- **GIVEN** 普通攻击目标已撤退，**WHEN** 轮到该攻击，**THEN** 改打第一个存活敌人。
- **GIVEN** 单体技能目标已撤退且无合法目标，**WHEN** 轮到该技能，**THEN** 取消且技力不变。
- **GIVEN** 军粮目标兵力已满，**WHEN** 轮到该道具，**THEN** 取消且军粮数量不变。
- **GIVEN** 武将技力 2，**WHEN** 打开技能菜单，**THEN** 3 技力以上的技能置灰、不可选；**GIVEN** 测试中强制下达该指令，**WHEN** 执行，**THEN** 取消并提示，技力保持 2。
- **GIVEN** 目标已有破阵（物防 −20%，剩 1 回合），**WHEN** 再次施加破阵，**THEN** 不叠加为 −40%，持续时间刷新为 2。
- **GIVEN** 同属性有 +20% 与 −20%，**WHEN** 计算倍率，**THEN** 倍率为 1.0；任何组合下倍率不低于 0.2。
- **GIVEN** 施放持续 2 回合的效果，**WHEN** 施放当回合及下一回合结束，**THEN** 剩余回合依次显示 2→1→移除。
- **GIVEN** 某单位兵力降为 0，**WHEN** 后续动作轮到它，**THEN** 它不行动、不能被治疗或使用军粮。
- **GIVEN** 敌方全部撤退，**WHEN** 判定，**THEN** 胜利，刘关张各得等额经验（10／20／30 对应三战）、全队兵力与技力回满。
- **GIVEN** 新存档完成三战，**WHEN** 每战胜利后查看等级，**THEN** 依次为 2／3／4 级，第三战开始时可用三级技能。
- **GIVEN** 战败，**WHEN** 选择重试，**THEN** 编队、装备、库存、铜钱、经验和事件状态与战前快照一致，且奖励不会重复发放。
- **GIVEN** 已完成某战并领奖，**WHEN** 读取更早存档再完成该战，**THEN** 可正常领奖一次。
- **GIVEN** 第二战张梁兵力归零，**WHEN** 撤退，**THEN** 表现为部队溃退、不播放死亡或斩杀。
- **GIVEN** 武将在战斗中用掉技力，**WHEN** 进入后续回合，**THEN** 技力不增加；战斗胜利后回满。
- **GIVEN** 刘备兵力未满，**WHEN** 对自己使用整队，**THEN** 回复 floor(最大兵力 × 0.3)，不超过上限。
- **GIVEN** 关羽对物防 X 的目标使用破阵，**WHEN** 本击结算，**THEN** 伤害按物防 X 计算；该目标下一次受击按物防 X × 0.8 计算。
- **GIVEN** 本回合还有我方动作未执行，**WHEN** 最后一个敌人撤退，**THEN** 立即胜利，未执行动作不发生、不扣技力或道具。
- **GIVEN** 第一战，**WHEN** 敌方选目标，**THEN** 每个敌人攻击当前兵力最高的存活我方单位。
- **GIVEN** 第二／三战，**WHEN** 敌方选目标，**THEN** 每个敌人攻击与自己出战位相对的我方单位，该单位在回合开始时已撤退则改打兵力最低者；有技能的敌人只在第 3、6、9…回合用技能。
- **GIVEN** 任一战斗，**THEN** 不出现暴击、闪避、逃跑、连携、召唤、地形或复活。
