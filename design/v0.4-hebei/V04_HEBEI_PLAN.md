## 0. 一页概览

**0.4 玩什么**：讨董联军散去，袁绍以计夺冀州（编年），公孙瓒与袁绍开战。刘备被表为别部司马、试守平原令，**第一次有了自己的据点**：渤海平原上的平原城。玩家在平原县衙前接见县民、施仁政，简雍开设情报、田豫在兵营练兵；流寇犯境，刘备守城（战斗 9）。192 年，公孙瓒在磐河被文丑追杀，一位白马银枪的少年将军杀出——赵云（战斗 10，客将），他说出“从仁政所在”，此后随刘备行动。界桥之战，麴义先登死士与强弩大破白马义从，刘备殿后掩护公孙瓒撤退（战斗 11）。真定访赵云故里（轻量必做）；回平原领平原相，郡民刘平遣刺客，刺客不忍下手。

**情感曲线**：有了家（平原）→ 守住家（御寇）→ 知己（赵云）→ 惨败中的担当（界桥殿后）→ 仁政的回报（刺客不忍）。**人心第一次救了刘备的命。**

**规模**：

| 项目 | 数量 |
| --- | --- |
| 新战斗 | 3 场：战斗 9 平原御寇（全灭）、10 磐河救公孙瓒（客将＋护卫）、11 界桥殿后（阈值撤离）；全部半即时战棋，各有战场地图 |
| 可走区域 | R4 渤海平原（开放区域示范：平原城据点、高唐、平原津、两村三探索点；沿用探针 PR #18） |
| 剧情舞台背景 | 3 张：磐河岸、界桥战后、真定赵家宅院 |
| 过场 | 12 段，其中 3 段含选择 |
| 水墨画卷 | 新增 2 卷：⑦「磐河·白馬銀槍」、⑧「界橋」（版本收尾，盖“完成”印章）；0.3 画卷⑥去掉“完成”印章 |
| 新系统与扩展 | 5 项：客将（赵云，可操作，随队）、阈值撤离（撤到撤离区即胜）、据点雏形（平原：能人开设功能）、强弩敌兵、等级上限 9→12 |

**结尾**：刺客坦白离去，刘备领平原相；“后事预告”（193 北海、194 徐州），画卷⑧「界橋」＋“完成”，返回标题。
