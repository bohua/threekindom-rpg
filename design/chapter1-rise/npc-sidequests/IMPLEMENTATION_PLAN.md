# 第一篇章 NPC 与支线：R2–R8 核心层实装计划

日期：2026-10-30　负责：Claude（「搭建第一篇章其余野外区域」线程）　依据：用户 2026-10-29 “开始。”（只做核心层 47 条），总纲 §8、`10_REVIEW.md` §3–§4。R1 七张核心卡由涿蓟大地图线程做，本计划只做 R2–R8 的 37 张。

## 1. 做法

- **台词即设计稿原文**：`tools/npc/extract_lines.py` 把五个分区文件里带键的台词（表格行、行内“……”（dlg.…））抽成 `Resources/Text/npc_lines_ch1.json`（约 1500 句），游戏按键取字；设计稿改了重抽即可，不在代码里再抄一遍。设计稿里没写键的个别句子在代码侧补键。
- **脚本**：沿用现有剧情步骤（`StageScript`：Lines／Choice／Remember／Flag），每张卡一段，挂在它所在的可走场景的 FieldStoryController 上。
- **记忆键**：严格按 `10_REVIEW.md` §4 与剧本 v1.1 §16.1；旧的 0.2–0.5 键（如 `luzhi_cart`）读写处照登记表改名，读档时把旧键迁成新键。
- **人物图**：9 名新人物由 Codex 统一出图（`art/ch1-npc-concept` 设计图 → 九宫格 → 立绘），R1 线程共用；到图前用居民 Q 版换色占位。其余约 20 人一律居民 Q 版换色。

## 4. 实装记录（2026-10-30）

**A 段（已能走的场景，21 张）**：`SideQuestsEarly`（卢植大营阿禾①；安喜阿禾②、中山的酒）、`SideQuestsR5a`（会盟听书、坛上盟辞、鲍家兄弟的箭）、`SideQuestsR4`（千丈之堤、同簋、阿禾③④⑤、白马／白马不还、高唐旧吏）、`SideQuestsR8`（织席郎、背进城的孩子、使君的账、城头、什伍名籍、布席于路）。夜宴＝主线 E9（已有），读旧键 `liuping_assassin`。

**区域行旅（B 段前提）**：`RegionTravel`——主线据点（公孙瓒营、酸枣、平原、下邳）与各区域驿站的驿卒列出本年开放区域（`Chapter1Chronicle`），区域里可回主线所在地；190 年前不开放。区域剧情层 `ChapterFieldBuilderRegions`（R2、R3、R5a、R5b、R6、R7、R8），存档落驿站（`region:<id>`）。R1 的场景在涿蓟线程分支，合并后 192 年即可经驿卒去 R1 再进涿郡（“卢门·灵位前的字”）。PR #37 的天下沙盘飞行合并后接在 `RegionTravel.Go` 上。

**B 段（16 张）**：`SideQuestsR2`（县尉打督邮、中山马栏、滹沱头钓）、`SideQuestsR3`（卢营旧冢、一张过所；过所由平原青州从事毕谦发）、`SideQuestsR5aWild`（汴水夜话）、`SideQuestsR5b`（一把火、石经摹本、北邙兵书、井里只有水）、`SideQuestsR6`（缟素、华费新坟）、`SideQuestsR7`（稷门问答、景王祠、下密草鞋、孔北海、济南马群降级版）。

**偏差**：
- 平原 192 年刺客夜宴改为回县衙再触发（原为到达即播），让高唐旧吏等有可走时段。
- 阿禾界桥用降级版（带上＝负伤、不带＝缺席）。
- 鲍家兄弟比箭不做射箭小游戏，改为“全力射／让一箭”选择；汴水后的鲍信一幕放在虎牢后的剧情舞台里（酸枣营此后不再回来）。
- 千丈之堤的三趟搬运与夯土压缩为对白与过场；北邙填洞、甄官井淘泥同样只用对白。
- 孔北海一段在战斗 12 后才开放，那之后第一个可走的据点是下邳（194），所以实际在 194 年经行旅回青州听。
- 甄家谷筹需要可走的真定，暂缓；真定兄长托付是主线场景。
- 新人物在 Codex 九宫格到前用居民 Q 版换色。
