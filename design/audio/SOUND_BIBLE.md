# 声音圣经 v0.1（配乐）

状态：草案（audio-director，2026-10-26），随 ADR-0011 一起待用户确认。所有提示词卡片、API 提示词都从这里取统一前缀。

## 1. 声音身份

- 一句话：**中国传统民乐为骨、电影管弦为肉的英雄史诗**，明亮、有人情味，不阴郁。白天、城镇、野外都要明快（呼应 2026-10-25 “白天色调明媚、不要昏黄”）。
- 标杆曲：`taoyuan_oath`（桃园结义），它的旋律动机就是全作主题动机。之后带“主题动机”（cue-sheet `motif=theme`）的曲子都从它变奏。
- 不要：电子合成器主奏、摇滚鼓组、现代流行和声、日式动漫腔人声、过度混响糊成一片。

## 2. 乐器表

| 角色 | 乐器 |
|---|---|
| 主奏 | 竹笛／梆笛、二胡、琵琶、古筝 |
| 色彩 | 箫、埙、笙、扬琴、古琴、编钟 |
| 打击 | 大鼓（战鼓）、堂鼓、锣、钹、梆子；电影感定音鼓只做低频支撑 |
| 铺底 | 弦乐组、低音提琴、圆号（只在大场面） |
| 人声 | 只在头目战、虎牢关、黄巾主题；男声合唱或吟唱，无歌词或用古风虚词 |

## 3. 调式与速度

- 以五声调式为主：宫（明亮、城镇）、徵（英雄、战斗）、羽（悲伤、黄巾）、商（紧张）。
- 速度参考：城镇 92–100，野外 108，行军 112，常规战斗 128，头目战 138，虎牢关 150，悲伤 64。

## 4. 混音与技术规格

- 响度：BGM 与 jingle 一律 −16 LUFS 积分（在循环段上测），真峰 ≤ −1.5 dBTP；由 `tools/music-inbox` 统一处理，Unity 里不再 normalize。
- 循环：前奏与循环分成两个文件（`<cue>__intro.wav` 与 `<cue>.wav`），循环段为整小节，接缝交叉淡化 80 ms。
- 中低频留给对白和音效：主奏在 1–4 kHz 不要过亮，避免盖住对白；以后加对白压低（ducking）。
- 命名：新曲 `mus_` 开头，提示音 `jng_`；已上线的三首保持原名。

## 5. Suno 统一风格前缀
