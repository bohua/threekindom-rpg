## 0. 一页概览

**0.3 玩什么**：安喜挂印之后，刘关张辗转数年；天下大乱，董卓入洛阳。玩家在天下图上看编年，看曹操献刀出逃、陈宫捉放。190 年，刘备投奔同窗公孙瓒，在北方军城里结识简雍、田豫，看白马义从，可选与白马骑将校场演武；随后南下酸枣会盟，以公孙瓒部属身份站在末席，看关羽温酒斩华雄；虎牢关前三英战吕布；董卓焚洛阳西走，诸侯在洛阳废墟各怀心思，联军瓦解，刘备随公孙瓒北返。

**情感曲线**：漂泊的失意 → 天下大乱的震动 → 同窗相投的温暖 → 末席的屈辱（袁术“弓手”）→ 温酒斩华雄的扬眉吐气 → 三英战吕布的豪情 → 焚洛阳的悲凉、联军散去的清醒：**名声有了，地盘还没有**。

**规模**：

| 项目 | 数量 |
| --- | --- |
| 新战斗 | 2 场：战斗 7 校场演武（选做）、战斗 8 虎牢关·三英战吕布（必做）；均为半即时格子战棋，各有战场地图 |
| 新可走场景 | 2 个：S4 公孙瓒营（军城）、S5 酸枣联军大营 |
| 新剧情舞台背景 | 5 张：洛阳相府、吕伯奢庄（夜）、盟主大帐、虎牢关前、洛阳废墟 |
| 过场 | 14 段（§5），其中 3 段含玩家选择 |
| 水墨画卷 | 新增 3 卷：④ 温酒斩华雄、⑤ 三英战吕布、⑥ 焚洛阳（版本收尾，盖“完成”印章）；0.2 画卷③去掉“完成”印章 |

**结尾**：联军瓦解、随公孙瓒北返，“后事预告”旁白（191 平原、192 磐河界桥、193 北海、194 徐州受托），接画卷⑥「焚洛阳」与“完成”印章，返回标题。停在 0.3，故事也能收尾。
