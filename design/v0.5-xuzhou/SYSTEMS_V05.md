# 0.5 新系统设计：后备换人、波次增援、下邳回声、篇章结算、等级 12→15

## 2. 后备换人
- 出战上限 3（本篇起取消 0.4 的“客将第 4 位”临时规则）。超过 3 人时，战前由**编成**决定上阵三人：主线战前用剧情舞台的选择框依次选三人（默认刘关张），其余进后备。
- 战中换人：轮到我方武将行动时，若有后备，武技菜单出现“换人”（不耗气势、耗本次行动）：该武将退到后备，后备第一人在原地登场，兵力与气势保持各自上次的值（未上阵者为满）。
- 后备武将不算“全军撤退”的一员；上阵者全部撤退即败，后备不自动顶上。
- 经验：参战与后备同吃经验（等额，沿用 V1“不按出战人数稀释”）。客将（赵云、太史慈）等级取刘关张最低值。

## 3. 波次增援
- 战斗配置中的回合事件 `Spawn` 让敌方增援在指定格登场（沿用 0.2–0.4 的 Spawn，按阵营生成）。横幅“第二波”“第三波”；目标栏写剩余波次。
- 战斗 13：第 3、5 回合两波；于禁在第二波，阈值 50% 后开撤离区（城门）。战斗 14：第 3、5 回合两波，曹仁兵力 < 50% 鸣金（敌方全体退走）即胜。

## 4. 下邳回声
- 下邳城人物的对白由**记忆与标记**选择：一人可有多条回声，按条件依次检查，取第一条满足的；条件为“记忆 who/key=value”或剧情标记。
- 必有的固定回声：糜竺、陈登（“合步骑十万”）、孙乾、孔融（“冢中枯骨”）、北海难民；条件回声：卢植槛车（A/B）、刘平刺客（A/B）、安喜送行（委托完成数）、真定赵兄（记忆）、田豫（结识）、老卒点破“白身”（董卓记忆存在即出现）。
- 回声全部听过不是三让的前提（三让在州府正堂随时可触发），但每听一条声望＋0（不加数值，只记“回声 n/m”显示在目标栏）。

## 5. 篇章结算
- 三让受印、赵云辞别、尾声之后播放：天下图上回放刘备足迹（按 ChapterStep 依次经过的城池节点连线），然后三张结算卡：战斗（场数、选做是否完成）、人物（记忆条数、结识的能人）、声望与关键选择（槛车、督邮、众望、刺客、受印前的回声数）。
- 结算卡文字由存档状态生成，不写入新的剧情状态。
