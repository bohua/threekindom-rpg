## 1. 范围（/scope-check）

| 项 | 做法 |
| --- | --- |
| 试验区 | 平原城北 x −40..340、z 10..250（约 380×240 m）：北官道、跨河平桥、东西向小河、一片密林、一座低丘、农田与草地。四周加空气墙，外围 60 m 景物保留作远景；北村（像素民房）整片移除，免得两种画风混在画面里 |
| 贴图 | 试验区实际用到的 52 张环境贴图，各出 A、B 两版；同名同尺寸，几何、平铺、贴片落地点都不改 |
| 调色 | 两个水墨版去掉共享暖色 LUT，改中性日光、宣纸白雾；原版保持探针原样 |
| 对比 | 场景内按 V 键（手柄 LB）在“原版／水墨留白 A／水墨淡彩 B”之间切换；`-ink 0|1|2` 启动参数用于截图 |
| 不做 | 不改 Bohai_Plain 主场景、不改城镇和人物、不写新着色器（只换贴图和后处理）、不做天下图 |

**结论：PASS。** 试验用独立场景，净增 1 个场景、1 个编辑器生成器、1 个试验用切换组件。

## 2. 美术总监评审：效果图（Codex `art/bohai-ink-concept`，已批准）

| | A 水墨留白 | B 水墨淡彩（浅绛／小青绿） |
| --- | --- | --- |
| 观感 | 最“水墨”，宣纸米白底、墨分五色，辨识度极高 | 墨骨架不变，草、水、山上一层淡花青和赭石，明快通透 |
| 昏黄问题 | 彻底解决 | 解决（暖色只剩淡赭点缀） |
| 人物可读性 | 刘关张的橙、绿、黑在纸白底上非常突出 | 同样突出，略低于 A |
| 地形可读性 | 草地、道路、水面只靠明度区分，大面积时容易单调、像雪景 | 水是淡蓝、草是淡绿，玩家一眼分得清能走和不能走 |
| 和城镇衔接 | 与平原城暖黄苇顶反差大，进出城跳色明显 | 衔接较顺 |
| 风险 | 1 km² 整区用 A 会显得空、冷；适合作为特殊区域（如雪原、梦境、回忆）| 设色控制不好会回到“灰绿脏”，需要守住低饱和高明度 |

**评审建议：** 以 B 为整片野外的候选方向，A 作为对照和特殊区域储备；最终由用户试玩后决定。两版都要求像素网格清楚（Point 过滤、有限色阶、二值透明），因为人物仍是 V3 128 像素 Q 版，背景若出现照片级晕染会和人物脱节。

## 3. 贴图规格（Codex `art/bohai-ink-ground`、`-decals`、`-props`）

- 与同名原图同尺寸；30 px/m；平铺轴相同；透明的二值透明，不透明的全不透明。
- 贴片（树、灌木、岩石、芦苇）落地点在底边中央，主体贴底边。
- A ≤24 色（宣纸 #EEE9DD 到浓墨 #2A2A2A）；B ≤40 色（墨骨架＋淡花青、淡草绿、淡赭、浅绛）。不烘焙光影、不写字、不加印章。
- 一城一景：画黄河下游平原的空阔疏朗，杨柳槐榆、盐碱斑、农田、低丘；不要江南、竹子、奇峰。

导入位置：`Assets/_Project/Art/Environment/BohaiPlain/Ink/A/`、`Ink/B/`（文件名去掉 A_/B_ 前缀）。生成器为每个用到这些贴图的单材质渲染器克隆一份 A、B 材质（`Ink/Materials/`），原材质不动。

## 4. 验收

- 三个版本同一镜头截图对比（官道桥头、密林边、小丘前、俯瞰）。
- 自动测试全绿；Windows 构建 `builds/bohai-ink/InkTrial.bat` 可双击试玩。
- 用户试玩后决定：全区推广哪个方向，还是放弃。推广时再评估工时（全区约 52 张贴图×1 版，加城镇如何衔接）。
