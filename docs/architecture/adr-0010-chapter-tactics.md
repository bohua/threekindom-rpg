# ADR-0010: 0.2 黄巾篇三场战斗改用战棋（兵书战棋原型接入主线）

## Status

Proposed（用户 2026-10-25 要求改模式；本记录描述实现方式，待用户确认）

## Context

用户 2026-10-25 原话：“这里的几场战斗，我想现在开始就改成我们之前做虎牢关的那种战斗模式。不再是回合制的 RPG，而是地图的 SLG。”

0.2 的第四到六战（颍川夜战、广宗救董卓、安喜剿匪）原先用 ADR-0002 的回合制战斗核心实现，含战中事件（火攻、援军、护送、张角退走）。兵书战棋原型（`Assets/Prototypes/BingshuTactics`，PR #14）已有半即时 AT 行动条、格子地图、高低差、ZOC、武技与兵书回路策略、虎牢关地图和 HD-2D 画面，但只有两张写死的关卡，与主线的成长、奖励、存档、剧情不相连。

## Decision

1. 只改第四到六战。Alpha 0.1 的第一到三战保持回合制，不在本次范围。
2. 原型代码原地接入，不搬目录、不改命名空间：新增 `TacticsGame.Chapter.cs`，用数据（`TacticsStageDef`）描述地图、双方单位、战中事件和结束回调；`TacticsGame.Chapter` 为空时原型照旧运行两张原型关卡。原型程序集仍不引用任何正式代码。
3. 桥接放在 UI 程序集（`ChapterTactics`，场景内、先于 `TacticsGame` 执行）：
   - 我方数值由主线成长公式算出（`BattleRules.Compute`：兵力、物攻物防、计攻计防、速度，含装备加成），等级、武技按已学技能；策力＝技力上限×4；移动力骑 5／步弓 3／军师 2，射程弓 3、军师 2。
   - 敌方用原遭遇表的武将与等级，地图上另加两名同兵种小卒（末位敌将等级−1）。
   - 战中事件按原遭遇改到地图节奏：颍川第 3 回合火起（干草格变成火、敌军混乱 2 回合并损兵 10%），第 6 回合援军杀到敌军退走；广宗坚持到第 6 回合或张角兵力低于 30% 即退走，董卓本阵倒下即败；安喜全灭山贼。
   - 回合＝AT 时钟每 100 一回合。
   - 胜利后与回合制相同交还主线：`RecordVictory` 只发一次奖励（经验、铜钱），写入 C4／C8 记忆，播放战后对白，再进入原有的剧情舞台或安喜县。战败不写任何状态，重开本场即还原战前。
   - 进入场景时写战前自动档（与回合制相同的位置标记 `battle_4…6`），场景名不变，读档与流程不改。
4. 美术：先由 Codex 出三张战场效果图（`art/v02-tactics-concept`），地块按用户 2026-10-25 要求做高清手绘质感（`hd_<地形>` 贴图，有则覆盖原型的像素地块）；人物仍为 128 像素 Q 版，0.2 新角色先用现有像素表。
5. 新增地形“树林”（移动耗 2、骑兵 3）和“火”（不可通行，只由事件生成）。

## Consequences

- 正面：0.2 的战斗与虎牢关原型同一套手感；主线成长、奖励、存档、剧情不变；回合制核心与其测试不受影响。
- 负面：原型代码（单一大类、IMGUI 界面）进入正式流程，技术债留待后续重构；兵书回路配置只在本场内存中，不写存档；战斗中暂不能使用军粮；敌方不用武技，只有张角用策略。
- 数值未经平衡：自动测试中电脑代打可在第 6、6、8 回合通关三场，人工手感待试玩。

## Verification

- PlayMode `ChapterFlowTests` 从卢植大营一路打到安喜结尾，三场战棋由电脑代打通过、奖励与记忆写入、等级到 7。
- 其余 EditMode／PlayMode 测试保持通过；Windows 构建。
